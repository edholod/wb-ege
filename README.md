# WB ЕГЭ

Независимое учебное мини-приложение для сотрудников ПВЗ. Не является официальным экзаменом Wildberries.

## Публикация экспертного банка

Редакция банка: `expert-20261101-afbd88a3b0`.

1. Обновить действующий Worker, сохранив базу данных и секреты.
2. Опубликовать `app.js`, `questions.json` и `index.html` одной редакции через GitHub Pages.
3. Дождаться успешного этапа deploy в Actions и полностью переоткрыть Mini App через WebApp-кнопку бота.

Сообщение «вопросы и сервер разных редакций» означает, что публикация или обновление клиента ещё не завершены.

Серверный код, ключи ответов и приватные материалы аудита в публичный репозиторий не загружать.
